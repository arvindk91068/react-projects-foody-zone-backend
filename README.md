# 🍔 Foody Zone - Food Delivery Backend API

A complete, scalable backend API for a food delivery application built with Node.js, Express.js, and MongoDB. This backend powers restaurant management, order processing, cart functionality, and user authentication.

## ✨ Features

### 🍽️ Menu Management
- **CRUD Operations** - Create, Read, Update, Delete menu items
- **Category Filtering** - Filter by breakfast, main course, desserts, etc.
- **Search Functionality** - Search menu items by name or description
- **Popular Items** - Mark and filter popular dishes
- **Dietary Tags** - Vegetarian, Vegan, Spicy level indicators

### 🛒 Smart Cart System
- **Real-time Calculation** - Automatic cart total calculation
- **Discount Application** - Promo code integration
- **Delivery Fee Logic** - Free delivery over $25
- **Tax Calculation** - Automatic tax computation

### 📦 Order Processing
- **Order Placement** - Complete order workflow
- **Order Tracking** - Real-time order status updates
- **Order History** - User order history
- **Estimated Delivery** - Smart delivery time estimation

### 🔐 User Management
- **JWT Authentication** - Secure user authentication
- **User Profiles** - Profile management
- **Order History** - Track user orders
- **Address Management** - Multiple delivery addresses

### 🎯 Promo & Discounts
- **Promo Code Validation** - Validate discount codes
- **Multiple Discounts** - Percentage-based discounts
- **Minimum Order** - Conditional discount application
